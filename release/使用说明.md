# 泰拉瑞亚 投影MOD 使用说明

> 这份文件就是全部说明书。**装不上、装坏了先看第八节「常见问题」**，那里按「你会怎么描述这个问题」写的。
>
> 文件位置：安装好后，同一份说明在游戏目录里叫 `投影MOD_使用说明.md`；zip 包里叫 `使用说明.md`。
> 一页纸版本：`安装前必读.txt`。

---

## 一、三步装好（只看这一节也能装完）

1. **退出泰拉瑞亚**（Steam 里也不要让它显示「正在运行」）；
2. **双击** `TerrariaProjection_Setup_v1.3.0.exe`，Windows 弹「是否允许此应用对你的设备进行更改」→ 点 **【是】**；
3. 窗口里确认游戏目录没错 → 点 **【开始安装】** → 进度条跑完，弹「**安装完成！**」→ 点【确定】→ 点【关闭】。

然后：**双击桌面上新出现的「启动泰拉瑞亚投影MOD」**进游戏，按 **NumPad0**，就能看见投影了。

装不上、双击没反应、杀软报毒、装完没变化 → 直接跳到 **[第八节 常见问题](#八常见问题按你遇到的样子写的)**。

---

## 二、开始之前：三个必须满足的前提

| 前提 | 为什么 | 不满足会怎样 |
|---|---|---|
| **泰拉瑞亚是 Steam 正版** | 本 MOD 只是一份「外挂插件」，**不带游戏本体、不带存档** | 没有游戏就无处可装 |
| **游戏完全退出**（Steam 里也别让它显示正在运行） | 安装要替换 `Terraria.exe`，游戏开着文件就被占用 | 安装失败，提示「检测到游戏正在运行」 |
| **给管理员权限** | 安装要写游戏目录、要改 `Terraria.exe`，普通权限做不到 | 双击没反应，或装到一半报错 |

- 系统要求（Windows 版本、支持的泰拉瑞亚版本）见 **[第十节](#十系统要求)**。
- 安装**不需要**另外装 .NET：单文件 exe 自带运行时，zip 方式用的是系统自带的 .NET Framework。

## 三、安装（两种方式，任选一个）

### 方式 A：双击 exe（推荐，最简单）

1. 退出泰拉瑞亚；
2. **双击** `TerrariaProjection_Setup_v1.3.0.exe`（约 64 MB，下载慢一点是正常的）；
3. Windows 弹出**用户账户控制**：「是否允许此应用对你的设备进行更改？」→ 点 **【是】**；
   （没有这一步弹窗 → 说明没提权成功，右键 exe → **以管理员身份运行**）
4. 安装器窗口会显示它自动找到的游戏目录：
   - 显示「**已自动找到游戏目录（…），点「开始安装」**」→ 直接点 **【开始安装】**；
   - 显示「**没有自动找到游戏，请点「浏览…」**」→ 点 **【浏览…】**，选那个**里面有 `Terraria.exe`** 的文件夹
     （Steam 默认一般在 `C:\Program Files (x86)\Steam\steamapps\common\Terraria`，
     装在其他盘就是 `<那个盘>\steam\steamapps\common\Terraria`）；
5. 等进度条跑完 → 弹「**安装完成！**」→ 点【确定】→ 点【关闭】。

> 安装器会打印「安装完成。」并弹窗列出：原版备份叫什么、快捷方式建在哪、日志在哪。
> 安装器日志：**exe 旁边**的 `install.log`（写不进去时在 `%TEMP%\install.log`），失败原因一定写在这里。

### 方式 B：zip + 安装.bat（方式 A 打不开时用）

1. **先把 zip 完整解压**到你喜欢的文件夹（例如桌面新建一个文件夹）。
   ⚠️ **不要**在压缩包的预览窗口里直接双击里面的文件——那样装不上；
2. 进解压出来的文件夹，**右键 `安装.bat` → 【以管理员身份运行】**；
   （`安装.bat` 是批处理，**不会自己弹 UAC**，必须右键提权。直接双击可能一闪而过、什么都没发生）
3. 黑窗口会自己跑：找游戏目录 → 备份 `Terraria.exe` → 打补丁 → 复制文件 → 建桌面快捷方式；
   最后显示「**安装完成！**」，按任意键结束。
   - 要是提示「自动找不到游戏」，把游戏文件夹**拖进黑窗口**回车，或手动输入路径回车。

> 方式 B 和方式 A 装的是一模一样的东西，只是没有图形界面。
> 两种方式的**卸载都靠游戏目录里的 `卸载.bat`**。

### 安装到底做了什么（不用管，知道就好）

1. **按版本备份原版**：`Terraria_backup_<版本>_vanilla.exe`（例 `Terraria_backup_1.4.6.1_vanilla.exe`）——卸载就靠它；
2. **给 `Terraria.exe` 打补丁**：只在程序入口加一句「加载插件」，游戏本体逻辑没被改；
3. **复制插件文件**进游戏目录（见下一节的文件清单）；
4. **建桌面快捷方式**：`启动泰拉瑞亚投影MOD`（图标是模组图标）。

## 四、装好的样子

### 桌面上

- 多一个快捷方式 **`启动泰拉瑞亚投影MOD`**（图标是青色「ME」图形的模组图标），双击它就是启动打了补丁的泰拉瑞亚。
- 如果桌面上已经有**同名文件夹**，安装器会自动改名成 `启动泰拉瑞亚投影MOD (2)` 之类，**不会覆盖你已有的东西**；
  装完看到 `(2)`、`(3)` 也算正常，随便点哪个都行（点错的那个是旧安装，也能启动）。
- 不想用快捷方式也行：从 **Steam 正常启动**同样有效（补丁打在游戏本身上）。

### 游戏目录里（这些文件都在，缺一个都可能是没装完）

| 文件 | 是什么 | 要动它吗 |
|---|---|---|
| `Terraria.exe` | 游戏主程序，已被打补丁 | **不要手动改/覆盖** |
| `Terraria_backup_<版本>_vanilla.exe` | **原版备份**，卸载/还原靠它，名字带游戏版本号 | **千万别删**，删了就得靠 Steam 校验 |
| `ProjectionMod.dll` | 插件本体（功能都在这里面） | 别删 |
| `0Harmony.dll` | 插件运行需要的补丁库 | 别删 |
| `ProjectionMod.bp` | 演示蓝图（第一次进游戏看到的那座小建筑） | 可以换成自己的 |
| `ProjectionMod.ico` | 桌面快捷方式的图标来源 | 无所谓 |
| `卸载.bat` | 卸载 / 还原原版 | 留着 |
| `投影MOD_使用说明.md` | 就是这份说明书 | 留着 |
| `安装前必读.txt` | 一页纸版步骤 | 留着 |
| `蓝图编辑器.html` | 网页版蓝图编辑器，双击即用 | 留着 |
| `ProjectionMod.log` | **插件日志**（第一次进游戏后才会出现） | 出问题把它发给作者 |
| `Blueprints\` 文件夹 | 你保存/放进去的 `.bp` 蓝图 | 这是你的东西 |

> 游戏目录在哪？Steam 库里右键「泰拉瑞亚」→ 管理 → **浏览本地文件**，弹出的文件夹就是。

### 日志在哪（出问题必备）

| 日志 | 位置 | 里面有什么 |
|---|---|---|
| 插件日志 `ProjectionMod.log` | **游戏目录** | 每次进游戏追加一段，第一行是时间 + `=== ProjectionMod init ===`；装好会有 `兼容自检: 11/11 项通过，全部正常` |
| 安装器日志 `install.log` | **exe 所在文件夹**（写不进去时在 `%TEMP%\install.log`） | 6 个步骤的每一步结果、失败原因、备份文件名、快捷方式路径 |

## 五、怎么验证真的装好了

**验证一：进游戏看投影**

1. 双击桌面 **`启动泰拉瑞亚投影MOD`**（或从 Steam 启动）→ 进任意世界；
2. 出生点附近应该出现一座**半透明的「幽灵建筑」**（演示蓝图 `ProjectionMod.bp`）；
3. 按 **NumPad0**：投影**关掉**；再按一次：**重新出现**。
   - 没反应先看 **NumLock 灯有没有亮**（小键盘热键要 NumLock 开启）；
   - 笔记本没有小键盘时，要外接键盘或按 `Fn+NumLock` 打开模拟小键盘。

**验证二：看日志**

用记事本打开游戏目录里的 `ProjectionMod.log`，最新一段应该长这样：

```
2026-11-25 21:53:10  === ProjectionMod init ===
2026-11-25 21:53:10  runtime: 4.0.30319.42000
2026-11-25 21:53:11  Harmony patches applied OK (attempt 1)
2026-11-25 21:53:13  兼容自检: 11/11 项通过，全部正常
```

- 有 `=== ProjectionMod init ===` + `兼容自检: 11/11` → **装好了**；
- 有 `=== ProjectionMod init ===` 但没有 `兼容自检 11/11` → 游戏版本变了，见第八节「游戏更新后 MOD 没了」；
- 日志文件**根本没生成** → 补丁没生效，见第八节「装完进游戏没变化」。

## 六、快捷键（NumPad 热键需要 NumLock 开启）

| 按键 | 功能 |
|---|---|
| `NumPad0` | **投影显示 开 / 关**（最常用的一个） |
| `NumPad1` | 自动补料 开 / 关（光标悬停缺料格时自动换出手上的对应材料） |
| `NumPad2` | 材料清单 HUD 开 / 关（屏幕**左下角**显示还差什么材料） |
| `NumPad3` | 蓝图验证：统计 正确 / 缺失 / 错放 / 多余，并列出问题坐标 |
| `NumPad4` | 建造模式循环：**关闭 → 标准（空位放行）→ 严格（空位也禁止）** |
| `NumPad5` | 把当前蓝图区域里的真实建筑**保存成蓝图**（存到 `Blueprints\`） |
| `NumPad6` | 循环切换蓝图（`Blueprints\` 和游戏目录里的 `.bp`） |
| `NumPad7` | **打印机 开 / 关**（单机专用）：按 方块 → 背景墙 → 物件/家具 → 电线 → 促动器 的顺序自动补 |
| `NumPad8` | （**空号，没有功能**） |
| `NumPad9` | **蓝图列表**：`↑↓` 选择 · `PgUp/PgDn` 翻页 · `R` 改名 · `Delete` 删除（按两次确认）· `/` 搜索 · 再按 `NumPad9` 关闭 |
| `L` | **分层渲染循环**（9 种）：全部 → Y↓单层 → Y↑单层 → Y↓范围 → Y↑范围 → X→单层 → X←单层 → X→范围 → X←范围 |
| `PgUp` / `PgDn` | 层号 ±1（按当前方向数，「第 1 层」= 那个方向上最近的一层） |
| `Shift + PgUp/PgDn` | 范围模式下**厚度** ±1 |
| `Ctrl + 方向键` | **移动蓝图**（整体挪位置） |
| `Ctrl + Shift + 方向键` | 同上，但每次移动 **8 格**（快速挪远） |

> - **为什么用小键盘**：`F5~F11` 是游戏自带的调试键（FPS、内存占用），用它们会互相打架；
> - **蓝图列表打开时**：`↑↓`、`PgUp/PgDn`、`L`、`Ctrl+方向键` 都先给列表用，关掉列表才恢复翻层/移动；
> - **投影吸附常开**（没有开关）：手持与投影格匹配的材料时，点投影附近就能落到最近的缺失格上；
> - **放置距离**完全按游戏原生规则走（建筑工魔包、延长握爪照常生效），超出范围时屏幕会提示「超出放置距离：走近一点」。

## 七、蓝图编辑器怎么用

发布包里带一个**网页版**蓝图编辑器 `蓝图编辑器.html`（游戏目录里也有一份）：

1. **双击 `蓝图编辑器.html`** → 用浏览器打开（Edge / Chrome 都行，**不需要联网、不需要装任何东西**）；
2. 把 `.bp` 蓝图文件**直接拖进网页里**（页面上也写着「拖拽文件」），或点 **「打开…」** 按钮选文件；
3. 就能看到：方块按类型着色、斜坡画对角三角、半砖画下半块、墙用斜纹、电线四色、促动器、油漆——都能单独开关；
4. 能直接改：画笔 / 橡皮 / 吸管、笔刷 1×1 / 3×3 / 5×5、逐格设斜坡 0-4、四色电线、漆；
   **材质替换**（例如「石头 → 大理石」）可以存成映射表，先预览再应用，`Ctrl+Z` 撤销；
5. 改完**导出 `.bp`**，丢进游戏目录或 `Blueprints\` 文件夹，游戏里按 `NumPad6` 切换即可。

> 保存出的 `.bp` 与游戏完全兼容（12 列格式，列序不变），游戏内 `NumPad5` 抓的蓝图也能直接打开。

## 八、常见问题（按你遇到的样子写的）

### 1.「双击 exe 没反应」/「一闪就没了」

- 十有八九是**没提权**：右键 exe → **【以管理员身份运行】**；
- 还是没反应：看 exe 旁边的 `install.log`（没有就找 `%TEMP%\install.log`），里面一定写了失败原因；
- 完全没有日志、窗口也不出：说明 exe 被**杀毒软件**拦了，见第 3 条；
- 最后手段：改用 **方式 B（zip + 安装.bat）**。

### 2.「提示要管理员权限 / 提示没有权限写入」

- 安装**必须**管理员权限（要改 `Terraria.exe`）。
- 方式 A：右键 exe → **以管理员身份运行**；
- 方式 B：右键 `安装.bat` → **以管理员身份运行**（直接双击不会提权）；
- 游戏装在 `C:\Program Files (x86)` 这类受保护目录时，尤其需要提权。

### 3.「杀毒软件报毒 / exe 被删了 / 说是病毒」

- **正常现象，不是真病毒**：本 MOD 要**修改 `Terraria.exe`**（给它打补丁），杀软对这类行为一律敏感；
- 处理：把安装包文件夹**加入白名单/信任区**，或先退出杀软再装、装完再开；
- 被删了：从隔离区**恢复**，或重新下载安装包（文件没坏，是杀软动的手）。

### 4.「装完进游戏一点变化都没有 / 没有投影」

按顺序查：

1. **是不是用新图标启动的**：桌面 `启动泰拉瑞亚投影MOD`（或 Steam 启动也行）。如果点的是旧快捷方式，可能指向别的游戏副本；
2. **游戏目录里有没有 `ProjectionMod.dll`**：没有 → 没装成功，重装；
3. **有没有 `ProjectionMod.log`**：没有 → 补丁没生效（`Terraria.exe` 被 Steam 还原了？），重跑一次安装器；
4. **投影是不是被关掉了**：按 `NumPad0`（注意 NumLock）；
5. **当前蓝图是不是空的**：按 `NumPad6` 切一个蓝图，或 `NumPad9` 打开列表选一个；
6. 还是不行：把 `ProjectionMod.log` 发给作者（见第十一节）。

### 5.「游戏更新之后 MOD 没了 / 投影不见了」

**这是设计如此，不是坏了**：Steam 更新会下载新的 `Terraria.exe`，把补丁冲掉。

- 处理：**重新运行一次安装程序**（关掉游戏 → 双击 exe → 【开始安装】）即可；
- 重装会为**新版本**再生成一份 `Terraria_backup_<新版本>_vanilla.exe`，旧版本备份原样留着（只对各自版本有效）；
- 装上后进游戏，日志里 `兼容自检: 11/11` 就说明新版本也没问题；如果是 `9/11 项通过，缺失 2 项`，
  说明游戏改得比较多，需要作者适配——把那几行日志发出去就行。

### 6.「卸载之后游戏打不开了 / 一进就崩」

多半是「**exe 和 Content 版本对不上**」——用错了备份。按下面做：

1. 先看游戏目录里的备份名：只有 `Terraria_backup_<当前游戏版本>_vanilla.exe` 才是对的
   （例：游戏是 1.4.6.1，就得用 `Terraria_backup_1.4.6.1_vanilla.exe`）；
2. 找到对应版本的这份备份 → **复制**一份出来改名成 `Terraria.exe`，覆盖游戏目录里那个（先关游戏）；
3. 找不到对应版本的备份 → **去 Steam 校验完整性**（第九节第 3 步），Steam 会把 exe 恢复成当前版本的原版。

> `卸载.bat` 本身有保护：**只认同版本的原版备份**，找不到就直接报错、绝不拿旧版本 exe 覆盖，所以
> 「卸载后打不开」基本都是**手工覆盖错了文件**（或者用旧版本 exe 手动替换过）造成的。

### 7.「多人联机能用吗？」

- **投影 / 放置限制 / 蓝图验证 / 材料清单**：纯客户端行为，**能用，也合法**（服务端看不到你屏幕上的幽灵方块）；
- **打印机（`NumPad7`）**：**别在别人服务器上用**。它是自动化放置，容易被视为作弊，也与服务器规则冲突；
  插件在多人客户端里默认不启用打印机。
- 一句话：**投影可以，打印机别用。**

### 8.「打完补丁 `Terraria.exe` 大小没变，是不是没成功？」

- **没变也正常**：补丁只是在入口加了一小段「加载插件」的 IL 引用，体积增减只有几十到几百字节，
  资源管理器显示的大小（按 KB/MB 取整）看起来可能一模一样；
- 判断装没装成功**别看大小，看日志**：`ProjectionMod.log` 里有 `=== ProjectionMod init ===` + `兼容自检: 11/11` 就是成功；
- 安装器的 `install.log` 里有 `补丁标记 : 安装前 x0 -> 安装后 x1`，这才是准信。

### 9.「按 NumPad0 没反应」

- **NumLock 灯亮了吗**？小键盘热键要 NumLock 开启；
- 笔记本没有独立小键盘 → 外接键盘，或按 `Fn + NumLock` 打开模拟小键盘；
- 数字键被输入法/游戏窗口捕获时也可能不灵：切回游戏窗口再按；
- 确认蓝图不是空的（`NumPad6` / `NumPad9` 选一个）。

### 10.「提示找不到泰拉瑞亚 / 找不到游戏目录」

- 说明你的游戏装在非常规位置。方式 A 点 **【浏览…】**、方式 B 直接把游戏文件夹**拖进黑窗口**；
- 游戏目录怎么找：Steam 库 → 右键泰拉瑞亚 → 管理 → **浏览本地文件**；
- 注意选的必须是**`Terraria.exe` 所在的文件夹**，不是它的上一层。

### 11.「用 zip 装的，桌面没有快捷方式」

- 方式 B 会用 `shortcut.ps1` 建快捷方式；如果被杀软/策略拦了会跳过（不影响游戏）；
- 手动做一个也一样：游戏目录里右键 `Terraria.exe` → 发送到 → 桌面快捷方式。

## 九、卸载与还原

### 情况一：正常卸载（把 mod 去掉，游戏还能玩）

1. **先退出游戏**；
2. 打开**游戏目录**，**双击 `卸载.bat`**（右键 → 以管理员身份运行更稳）；
3. 它会**先还原 `Terraria.exe`**（用同版本的原版备份），成功后提示「还原成功。」；
4. 插件文件（`ProjectionMod.dll`、`0Harmony.dll` 等）它**不会自动删**，按屏幕提示手动删掉即可；
   `Blueprints\` 文件夹是你的蓝图，**建议留着**；
5. 想彻底回到装之前：删掉上面这些文件、删掉桌面快捷方式即可，游戏本体已经恢复原版。

> 也可以命令行卸载/还原：`TerrariaProjection_Setup_v1.3.0.exe --restore "游戏目录"`。

### 情况二：只想还原原版 exe（游戏还留着 mod 文件也没关系）

备份文件命名规则是固定的：

```
Terraria_backup_<游戏版本>_vanilla.exe
例如：Terraria_backup_1.4.6.1_vanilla.exe
      Terraria_backup_1.4.5.8_vanilla.exe
```

- **版本号部分必须与你现在这个游戏版本完全一致**。1.4.5.8 的 exe 配上 1.4.6.1 的 `Content` 一定崩；
- 手工还原：关游戏 → 把那份备份**复制**出来 → 改名成 `Terraria.exe` → 覆盖游戏目录里的 `Terraria.exe`；
  多的旧备份不用删（不会自动生效）。

### 情况三：找不到同版本备份（最常见于「游戏更新过」）

1. 关掉游戏 → Steam 库 → 右键泰拉瑞亚 → **属性 → 已安装文件 → 验证游戏文件完整性**；
2. Steam 会把 `Terraria.exe` 恢复成**当前版本的原版**（补丁同时被清掉，mod 暂时失效）；
3. 想继续用 mod：重新运行一次安装程序，这次会生成 `Terraria_backup_<当前版本>_vanilla.exe` 这份干净备份；
4. 想彻底不用：到这一步就已经干净了，删掉插件文件即可。

> 为什么这么严？因为 `Terraria.exe` 和游戏目录里的 `Content` 是配套的。用错版本覆盖，
> 游戏会在启动日志里崩掉，比「还原不了」糟糕得多——所以卸载脚本**宁可报错也不乱覆盖**。
