# 泰拉瑞亚投影 Mod 使用说明（原版 1.4.5.8）

> 类似 Minecraft「投影（Litematica/Schematica）」的泰拉瑞亚原版工具：
> 全息投影、限制建造、自动补料、蓝图验证、建筑蓝图存取。**不无中生有**——
> 所有放置都走游戏自身逻辑，消耗真实物品，多人联机下投影/限制/验证均为纯客户端、合法。

---

## 一、这是什么

在原版泰拉瑞亚（**非 tModLoader**）上加载一个轻量插件，提供：

| 功能 | 说明 |
|---|---|
| 投影 | 把蓝图以“虚化贴图 + 状态色发光轮廓”叠在世界里：白=缺方块、蓝=缺墙、红=放错、黄=多余 |
| 自由摆放 | Ctrl+方向键 拖动蓝图到任意位置 |
| 自动补料 | 光标悬停缺料格时，自动把背包里的对应材料换到手上，直接点就放 |
| 放置限制（建造模式） | 只能放蓝图相同/同类物块（木材族、砖族可互替），严格档连空位都禁止 |
| 蓝图验证 | 一键统计 正确/缺失/错放/多余 并列出问题坐标 |
| 蓝图存取 | 保存建筑为蓝图文件、多蓝图循环切换 |
| 选取工具 | 手持木剑右键框选两个角，把现有建筑抓成蓝图（带贴图帧） |
| 材料清单 HUD | 左上角实时显示还差哪些材料 |
| 投影吸附 | 点投影附近即可：方块自动落到 3 格内最近的缺失投影格（手长内，装备加成原生生效） |

## 二、环境要求

- Windows 10/11，Steam 版泰拉瑞亚 **1.4.5.8**（其他版本不保证可用）；
- 小键盘（NumPad 热键需要 NumLock 开启）；
- 无需安装任何运行库（.NET Framework 系统自带）。

## 三、安装

1. 关闭正在运行的泰拉瑞亚；
2. 双击 **安装.bat**（会自动查找游戏目录；找不到可手动输入）；
3. 安装器会：备份原版 `Terraria.exe` → 打补丁 → 复制插件文件；
4. 通过 **Steam 正常启动**游戏，进入任意世界，出生点附近应出现演示投影。

### 给 Terraria_MultiRod 等自改 exe 也打补丁（可选）

命令行执行（把路径换成你的游戏目录）：

```
Patcher.exe patch "游戏目录" work
copy work\Terraria.exe.tmp "游戏目录\Terraria_MultiRod.exe" /y
```

> 补丁只在该 exe 入口加一行“加载插件”，与钓鱼等修改互不干扰。

## 四、热键表（NumLock 需开启）

| 按键 | 功能 |
|---|---|
| `NumPad0` | 投影显示 开/关 |
| `NumPad1` | 自动补料 开/关 |
| `NumPad2` | 材料清单 HUD 开/关 |
| `NumPad3` | 蓝图验证（看统计与问题清单） |
| `NumPad4` | 建造模式循环：关闭 → 标准（空位放行）→ 严格（空位也禁止） |
| `NumPad5` | 把当前蓝图区域内的真实建筑保存为蓝图（`Blueprints\` 目录） |
| `NumPad6` | 循环切换 `Blueprints\` 与游戏目录下的 .bp 蓝图 |
| `NumPad7` | 打印机 开/关（**单机专用**）：先补方块，再补**电线/促动器**；全程消耗真实背包材料，开了分层只打印当前层 |
| `NumPad9` | 蓝图列表（管理）：↑↓ 选择 · `PgUp/PgDn` 翻页 · `R` 改名 · `Delete` 删除（按两次确认）· `/` 搜索 · 再按 NumPad9 关闭 |
| `L` | 分层渲染模式循环（9 种）：全部 → Y↓单层 → Y↑单层 → Y↓范围 → Y↑范围 → X→单层 → X←单层 → X→范围 → X←范围 |
| `PgUp` / `PgDn` | 层号 ±1（按当前方向数，第 1 层 = 该方向的最近一层） |
| `Shift + PgUp/PgDn` | 范围模式的厚度 ±1 |
| `Ctrl + 方向键` | 移动蓝图（`Ctrl+Shift+方向键` 每次 8 格） |

> 不使用 F 键是因为 F5~F11 是游戏自带调试键（FPS/占用率等），避免冲突。
>
> **投影吸附常开**（无开关）：手持与投影格匹配的材料时，点投影附近 2 格内任意位置，
> 方块会自动落到最近的缺失投影格上；不需要精确点中空中那一格。
>
> **无支撑放置**：按住左键即可在**手长内的空位**直接放方块（简单方块，如土/石/木/砖），
> 不需要相邻支撑；松手即停，每次放置照常消耗 1 个材料。家具/火把/平台等多格物块仍交原版判定。
>
> **放置距离完全交给游戏原生规则**：加手长/放置速度的装备（建筑工魔包、延长握爪等）照常生效，插件不覆盖任何距离字段。
> 目标超出放置距离时 HUD 提示「超出放置距离：走近一点」。
>
> **HUD 位置**：材料清单在**屏幕左下角**（避开快捷栏/小地图），橙色提示与蓝图列表不受 NumPad2 开关影响。
>
> **分层渲染**：按 `L` 循环 9 种模式 —— 全部 / Y↓单层 / Y↑单层 / Y↓范围 / Y↑范围 / X→单层 / X←单层 / X→范围 / X←范围。
> 箭头是数层方向：`Y↑ 第2层` 就是“从下往上数第 2 排”，`X← 第1层` 就是“最右一列”，适合从一侧往另一侧推进施工。
> `PgUp/PgDn` 上下翻层、`Shift+PgUp/PgDn` 调范围厚度；HUD 显示如 `分层: Y↑ 单层 2/10`，
> 统计与吸附也只针对当前层。

## 五、典型流程

1. **拿蓝图**：**手持木剑右键**点两个角，把现成建筑抓成蓝图（自动入库并加载）；
   或直接把别人分享的 `.bp` 文件丢进游戏目录 / `Blueprints\` 文件夹；
2. **摆位置**：NumPad9 列表选蓝图（加载后**出现在你身边**），`Ctrl+方向键` 拖到要建的地方；
3. **建**：NumPad1 开自动补料、NumPad4 开建造模式（标准/严格），照着投影放置即可；
   放错的材料会被自动拦截，材料不足会被自动换到手上；
4. **验收**：NumPad3 验证；NumPad2 打开材料清单看还差什么；
5. **存库**：建完按 NumPad5 保存这栋楼，以后随处重建。

## 六、蓝图文件格式（.bp，纯文本）

```
# 注释
x,y,type,wall,frameX,frameY[,wire,actuator,slope,halfBrick,paint,wallPaint]
```

- `x,y`：相对蓝图左上角的格坐标；`type`=方块ID，`wall`=墙ID（0=无）；
- `frameX/frameY`：贴图帧（家具/多格物体靠它保存朝向与部件）；
- `wire`：电线位（bit0 红 / bit1 蓝 / bit2 绿 / bit3 黄）；`actuator`：促动器；
  `slope`：斜坡（0=无 1..4）；`halfBrick`：半砖；`paint`/`wallPaint`：方漆/墙漆；
- 前 6 字段的旧蓝图仍然兼容；后 6 字段由“抓取/保存建筑”自动写入；
- **投影里的电线画成细连线**（会连到相邻同色电线，和真实走向一致），促动器画细方框；
- 方块与墙的幽灵都用**游戏图集 + 帧**渲染（保存帧优先，其次世界采样校准帧，最后退回图集首格）；
  墙永远画在方块**后面**且更淡，不会把方块盖住；
- **该格已有别的方块/墙时，只画红色高光外框，不覆盖原贴图**（方便看清现状该拆还是该补）；
- **漆与斜坡可视化**：蓝图里带漆的格子，幽灵会按漆色着色（方块漆/墙漆各自上色）；
  带斜坡的格子画对角虚线提示（1/2 = 下半坡，3/4 = 上半坡），半砖画中间横虚线；
- 暂不保存箱子内容、牌子文字等 **tile entity**（后续可扩展）；
- 可在游戏外手工编辑，或从 TEdit 导出的建筑按此格式转换后使用。

## 七、卸载 / 恢复

- 运行 **卸载.bat** 一键还原原版 `Terraria.exe`（插件文件可按提示手动删除）；
- 游戏更新或 Steam「验证游戏文件完整性」会还原 exe 使补丁失效——重跑 安装.bat 即可
  （若游戏版本已不是 1.4.5.8，请先联系作者更新适配）。

### 兼容性自检（游戏更新后怎么排查）

插件启动时会做一次依赖自检，日志里固定出现一行：

```
兼容自检: 11/11 项通过，全部正常
```

如果游戏小版本更新改了内部字段/方法，这一行会变成 `9/11 项通过，缺失 2 项`，
并在上方逐条列出 `兼容自检: 未找到 Terraria.Player::ItemTimeIsZero（…）`。
把这几行发给作者即可快速定位——**不用重装、不用重下，日志本身就说明坏了哪一环**。
所有反射取成员的操作都走同一层（`Compat.cs`），新增功能也必须走它，避免以后再次出现“静默失效”。

## 八、常见问题

| 问题 | 处理 |
|---|---|
| 启动报错/黑屏 | 游戏更新过了？先跑 卸载.bat 再跑 安装.bat；仍不行请恢复备份并反馈 |
| 投影看不到 | 按 NumPad0 开显示；按 NumPad6 切回非空蓝图；重新进世界（自动加载 ProjectionMod.bp） |
| HUD 没字 | 按 NumPad2 开关；查看游戏目录 `ProjectionMod.log` 里的 `HUD 诊断` 行反馈 |
| 放进背包的东西没反应 | 检查 NumLock 是否开启 |
| 电线 / 油漆摆不上 | 已修：自动补料不再抢换手持工具（扳手、剪线钳、油漆刷、促动器）。手持工具时日志会写「自动补料: 手持工具…不抢换物品」 |
| 多人服务器 | 投影/限制/验证为纯客户端，理论合法；自动补料和打印机类自动化行为请遵守服务器规则 |
| 想换热键 | 联系作者，或自行修改源码重编译（csc 即可，无需装 VS） |

## 九、图标与快捷方式

安装完成后会有：

- **桌面快捷方式**「泰拉瑞亚投影MOD」——指向 `Terraria.exe`，图标就是本模组的图标
  （安装脚本自动创建；不想用可自行删除，不影响游戏）；
- **游戏目录**里的 `ProjectionMod.ico`（快捷方式图标源）与内嵌到 `ProjectionMod.dll` 的 Win32 图标；
- **分享包文件夹**自带图标：解压后如果没显示，双击 `设置文件夹图标.bat` 即可
  （原理是写 `desktop.ini` 并给文件夹加只读属性）。
